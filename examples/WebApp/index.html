client-sf-oauth — web server flow

This page is a static landing page for the example in index.ts. Start the app (see README.md) and open http://localhost:3000/; the app redirects to /oauth, which builds the authorize URL with a PKCE challenge and a single-use state, then sends your browser to Salesforce.

Log in with Salesforce

After you approve, Salesforce redirects to /getAccessToken?code=…&state=…, where the app checks the state and redeems the code with the stored PKCE verifier.
